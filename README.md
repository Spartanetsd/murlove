# МурLove ❤️ Твій Ігор

Романтичний PWA-застосунок для Мар’яни: пухнастики, обійми, сюрпризи, сміх і любов від Ігоря.
Працює на iPhone як звичайний застосунок з головного екрана, без інтернету, без акаунтів, реклами та стеження.

## Публікація на GitHub Pages з iPhone

Усі файли лежать в одній папці, без підпапок. Готова збірка вже всередині (`index.html`, `app.js`, `app.css`), нічого збирати не треба.

1. Розпакуй архів у застосунку «Файли» (торкнись архіву).
2. Відкрий github.com → **New repository** → назва `murlove` → **Public** → **Create repository**.
3. Натисни **uploading an existing file** → вибери **всі** файли з розпакованої папки → **Commit changes**.
4. **Settings → Pages → Build and deployment**: Source — **Deploy from a branch**, гілка **main**, папка **/ (root)** → **Save**.
5. Через 1–2 хвилини сайт буде тут: `https://spartanetsd.github.io/murlove/` (якщо логін інший — підстав свій).
6. На телефоні Мар’яни відкрий посилання **в Safari** → **Поділитися** → **На початковий екран**.

> Важливо для iPhone: фото й голосові, додані у Safari, і ті, що додані у встановленому застосунку, зберігаються окремо. Тож спершу встанови застосунок на головний екран, а потім додавай фото та записуй голосові вже в ньому.

## Особисті тексти без перезбирання — `personal.json`

Файл можна редагувати прямо на GitHub з телефона (олівець ✏️ → Commit). Порожнє поле — лишається текст за замовчуванням.

- `ourDate` — ваша дата у форматі `2024-05-17` (з’явиться «Разом уже N днів»).
- `homeMessage` — послання на головному екрані.
- `hugMessage` — текст після обіймів.
- `confession` — приховане освідчення, кожен абзац окремим рядком у лапках через кому: `["Мар’янко,", "Перший абзац", "Другий абзац"]`.
- `confessionSign` — підпис під освідченням.
- `extraLove` — твої власні послання, які додадуться до кнопки «Отримати любов».
- `myReasons` — твої особисті причини «чому я тебе кохаю». Вони покажуться першими, перед стандартними.
- `myNotes` — твої записочки дня.
- `myApologies` — твої власні слова для «Мирилки».

Найсильніше спрацюють саме твої слова: 3–5 особистих причин і одна справжня спогадова записочка зроблять застосунок по-справжньому вашим.

Стеж за лапками й комами: якщо файл зіпсується, застосунок просто візьме стандартні тексти.

## Оновлення застосунку

Якщо замінюєш `app.js`, `app.css` або `index.html` — заміни й `sw.js` з нового архіву (або зміни в ньому рядок `const VERSION = 'murlove-1.1.0'`, наприклад на `1.1.1`). Тоді телефон підтягне нову версію після наступного відкриття. Для `personal.json` цього робити не треба.

## Розробка на комп’ютері (React + TypeScript + Vite)

```bash
npm install
npm run dev      # відкриє /dev.html з гарячим перезавантаженням
npm run check    # перевірка TypeScript
npm run build    # готовий сайт у папці dist/ (теж плаский)
```

Після збирання скопіюй вміст `dist/` у корінь репозиторію (замінивши `index.html`, `app.js`, `app.css`) і зміни `VERSION` у `sw.js`.

## Дозволи й особливості iPhone

- **Звук** вмикається після першого дотику (так вимагає iOS). Гучність і звук — у налаштуваннях і кнопкою 🔊. Колискова за замовчуванням вимкнена.
- **Беззвучний режим:** за замовчуванням звуки грають і в ньому (бо їх запускає сама Мар’яна дотиком). Можна вимкнути в налаштуваннях.
- **Вібрація:** легкий тактильний відгук на iOS 18 і новіших; на Android — звичайна вібрація.
- **Трусіння:** вмикається в налаштуваннях, iPhone попросить дозвіл на «Рух і орієнтацію».
- **Мікрофон:** iPhone попросить дозвіл при першому записі. Якщо відмовили — Параметри → Safari → Мікрофон. Голосове можна також додати готовим аудіофайлом.
- **Дані** (фото, голосові, налаштування) живуть лише на цьому телефоні. Видалення застосунку з головного екрана або очищення даних Safari їх стирає.
- **«Скажи без слів» і купони** відкривають системне меню «Поділитися» (Telegram, Viber, Повідомлення). Якщо меню недоступне — текст копіюється.
- **«Засинай зі мною»:** якщо заблокувати екран кнопкою, iPhone зупинить звук — тому екран лишається ввімкненим, поки грає колискова.
- **Менше руху:** застосунок враховує системне налаштування iOS, а також має власний перемикач.
